# 會計學闖關讀書站

手機也好用的讀書網站：課程、練習題、閃卡、模擬考、錯題本。

## 目前的課本

**會計學（三）**（技術型高中商管群・108課綱）

1. 現金及內部控制
2. 應收款項
3. 存貨
4. 證券投資
5. 長期營業用資產（不動產、廠房及設備）

## 加新課本

1. 在 `books/` 資料夾新增一個檔案，例如 `books/economics-1.js`，格式照 `books/accounting-3.js`。
2. 在 `index.html` 裡 `<script src="books/accounting-3.js"></script>` 下面加一行：

   ```html
   <script src="books/economics-1.js"></script>
   ```

也可以在網站裡按「加入新課本」，貼上課本資料（只存在自己的瀏覽器）。

## 進度

進度、經驗值、錯題都存在每個人自己的瀏覽器裡，不會上傳。
